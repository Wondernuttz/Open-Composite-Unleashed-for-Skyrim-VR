# OCU Custom EyeTracking Test 4.3.7 Hotfix 5

September 12, 2026. This is a complete alpha test package, incorporating the
tested local updates since Hotfix 4. Install the whole package and fully restart
Skyrim. Existing saved settings should be retained when updating an installation.

## Changes since Hotfix 4

- Fixed foveation and gaze-loss fixed fallback now reach the validated scene-depth
  route when an upscaler submits separate eye textures. RDM also accepts valid
  scene depth without a shared submitted color texture. This repairs an admission
  gap affecting both fixed and tracked modes; unsupported draws and invalid scene
  ownership still stay full rate.
- Slow, accumulated gaze movement is compared with the last uploaded rate-map
  center so it can trigger a new upload.
- DAPA suspends during gameplay menus including Favorites, invalidates its cached
  frame and resumes from a fresh real stereo pair after the menu closes.
- The moving-eye popup contains the ring settings and a center-cropped
  **PugDragon** detail preview. Video shows the green eye button and profile
  summary. **Fixed VRS / fallback** explains use without eye tracking and during
  gaze loss.
- Eye presets apply both boundaries, all three rates, custom-rate enablement and
  the eye half-rate cap. The names are **Quality**, Balanced, Performance and
  Aggressive. Other combinations are Custom. **Performance** is the fresh-install
  and full-reset default; saved profiles are preserved.

| Eye preset | Center / middle boundary | Center / middle / outer rate |
| --- | --- | --- |
| Quality | 0.30 / 0.65 | 1x1 / 1x2 / 2x2 |
| Balanced | 0.22 / 0.45 | 1x1 / 2x2 / 4x2 |
| Performance | 0.20 / 0.40 | 1x1 / 2x2 / 4x2 |
| Aggressive | 0.20 / 0.40 | 1x1 / 2x2 / 4x4 |

Each named eye preset enables custom rates and disables the eye half-rate cap.
Fixed profile settings and DAPA tuning are separate. RDM supports all seven rate
labels, including 4x2 and 4x4, using complete pixel-quad sampling; its footprints,
appearance and cost are not identical to NVIDIA hardware VRS.

Earlier terrain/cutout protection, separate compositor debug rings, input/session
recovery, Index grip/trackpad routing, RaceMenu keyboard recovery and DAPA mask
lifetime/exact-pixel fixes are included. The optional CSX API contracts are in the
source tree. The package does not contain a replacement CSX or OpenShaders DLL;
the effects-only backend needs a matching consumer, while the runtime backends
retain their existing compatibility paths.

## Component identity

For MO2, install the complete archive with its Configurator, root, Interface and
SKSE folders together, using the existing Root Builder setup. Launch the
Configurator from this mod. Back up a customized `root/opencomposite.ini` before
replacing the mod and restore it afterward to retain saved settings; replacing
the file with the supplied INI intentionally selects the public defaults.

The public INI enables eye tracking, selects Auto backend and Performance, and
leaves debug rings off. Fixed VRS / fallback remains off at its previous public
0.60/0.80 sizes. DAPA's existing public tuning remains: warp 1.00, rotation 1.00,
translation 0.00, depth 1.00, Loco 1.00, near fade 0.00, edge fade 3.00, auto-native
off and engage 50 FPS. Controller layouts and public upscaler settings are retained.

The drop name is Hotfix 5; tested components retain their individual build markers
instead of being rebuilt solely to change their labels. The package manifest
records its source snapshot and file hashes.

file except itself.

## Validation and remaining tests

- 340 Configurator checks passed for the final Quality/PugDragon naming update;
  the prior preset revision also passed at both tested DPI modes. The actual
  popup screenshot was inspected.
- 650 runtime configuration checks passed for preset/default/legacy behavior.
- 175 checks exercise the production separate-eye admission path, including
  fixed/tracked/fallback, incomplete pairs, invalid bridges and recovery.
- 17 native D3D11 RDM handoff scenarios passed, including depth-only ownership,
  CSX-style callbacks, MRT consumers and original state/depth preservation.
- Existing all-seven-rate masking and reconstruction probes passed on D3D11 WARP,
  NVIDIA and Intel adapters. No AMD adapter or headset was tested locally.
- Release build and installed component hash verification passed.

The geometry-routing fix adds no GPU pass or full-frame copy. Newly active RDM
uses its normal masking and reconstruction work. Fixture draw counts are not
end-to-end GPU time or Skyrim FPS measurements. Existing RDM viewport/layout
restrictions remain; moving-region DLSS/FSR reconstruction is not implemented.

Ni's dropout report and Fletch's no-effect/reflection reports still need matching
logs and headset retests. The repaired code paths do not establish that every
reported symptom is resolved. For tests, compare the same scene with the same
upscaler and saved settings, and record the effective backend and build markers.
Debug rings show the selected profile; actual draw counters are needed to establish
that eligible scene draws received foveation.
