# 4.3.11 Unstable source update

This branch contains the runtime marked `4.3.11-rdm-perf4` and the associated
bridge, Configurator, and regression-test changes.

- RDM reuses depth-mask preparation and retains private depth bindings across
  compatible draws. Read-only target queries preserve the game's logical depth
  binding. Resource consumers and incompatible draws restore native state.
- RDM diagnostics report admission, guide work, batching, and sampled GPU timing.
  These counters do not measure net FPS gains or prove final-image correctness.
- DAPA changes cover mask publication/lifetime, compute-state preservation,
  depth transfer, and loading/menu handoffs.
- Foveation changes include configurable ring previews, blackout handling,
  debug overlays, and geometry/state protections with regression coverage.
- Controller and Configurator changes cover binding persistence, trackpad
  editing, tracker status, and treadmill locomotion/calibration support.
- The audio-recovery source is experimental, disabled by default, and excluded
  from the current test packages. Shelved deployment binaries are not included.

## Current limitations

AMD RDM image correctness and net performance remain under investigation.
Nonzero masked-draw counts and successful synthetic tests are not a guarantee
of correct reconstruction in every Skyrim rendering configuration. A separate
CSX render-scale recovery patch is not part of this OCU repository update.

This source update does not create a release or replace installed mod files.

## Validation

Seventeen existing regression-test executables were rerun. Sixteen passed
without exclusions. The DAPA compute-state test passed with its hardware
dynamic-class-linkage fixture skipped after the baseline dispatch/readback
crashed before DAPA executed. WARP passed that fixture; the remaining hardware
state-preservation checks passed. This was not a fresh build of every component
or an end-to-end AMD headset validation.
