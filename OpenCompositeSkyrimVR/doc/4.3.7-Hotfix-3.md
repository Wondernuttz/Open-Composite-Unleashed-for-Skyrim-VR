# OCU Custom EyeTracking Test 4.3.7 Hotfix 3

This test addresses two different NVIDIA VRS compatibility gaps behind reproduced peripheral terrain colour loss and white foliage speckles. It retains the controller/runtime fixes from Hotfix 2. It does not require a replacement CSX DLL or shader override.

## Terrain depth blending

Some deferred landscape shaders compare a fine-pixel depth texture load with interpolated raster depth. Hardware coarse shading changes the interpolation location. An exact depth match can therefore fail even across a continuous sloping surface, suppressing the terrain material alpha across the peripheral region.

OCU now protects compiled pixel shaders that read raster depth and perform an integer Texture2D load. Classification includes stripped DXBC and is independent of shader filenames, DLL hashes and CSX versions. It runs at shader creation, not on each draw. This rule is conservative: unrelated raster-depth reads and loads in the same shader may also be protected. The installed CSX cache includes affected water and sky variants as well as landscape variants; main-scene and viewport eligibility still apply.

## Foliage with separate depth and colour passes

Grass can perform its alpha cutout in the depth pass and omit it from the subsequent colour shader. Correct depth coverage alone does not make that colour shader compatible with VRS: a coarse invocation can sample RGB from transparent texture texels and broadcast it onto surviving leaf pixels.

OCU observes submitted cutout depth draws on the canonical scene depth, identifies their single sampled Texture2D material, and retains that material's COM identity for the current frame. Later depth-equal colour draws sampling that material run at full rate, including colour shaders using additional normal or detail textures. Ordinary opaque materials remain eligible for VRS. Consecutive protected draws retain the same shading-rate state; the next ordinary draw restores coarse shading before it executes.

The policy is intentionally bounded to producers whose sampled material can be identified. It is not a claim that every foliage shader or mod is now compatible. The runtime reports untracked producers and ambiguous command-list coverage. Command-list ambiguity is limited to the current frame or until the main depth is cleared. There are no added GPU copies, readbacks or waits in this policy.

## Shared hook correction

RDM and the shared shader guard previously both attempted to own the viewport setter hook. That conflict could prevent RDM from arming. The viewport hook now has one owner, and the draw observer uses the existing hook infrastructure so switching between hardware VRS and RDM does not create competing draw hooks. RDM's shader classification remains separate from the new NVIDIA coarse-interpolation hazard.
